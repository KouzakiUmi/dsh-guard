# dsh-auto-review-router

为 DeepSeek Harness 的 Auto 预设提供可配置模型审查、人工审批回退和审批历史。包版本 `0.3.3`，验证基线 DSH `0.2.1-alpha.1`。安装方式见 [仓库 README](../../README.md#安装)。

## 快速使用

1. 在「设置 → 内置插件 → Auto 审查路由」启用插件。
2. 从已配置模型目录选择审查模型与支持的思考深度，或保留会话路由回退。
3. 保存配置，在需要审查的会话中选择 Auto。
4. 在会话「审批历史」查看阶段记录，在设置页查看或撤销目录授权。

启用仅注册 Auto，不自动切换会话权限或审批策略。模型目录选择不测试可达性；每次实际模型审查会额外消耗一次请求。

## 审批流程

仅 Auto 调用进入审查；无 agent、非 Auto 调用继续原流程。健康启用时外层 `run_code` 作为传输跳过，其内部工具调用仍审查。代码中不经工具的副作用不在覆盖范围。

| 情况 | 行为 |
| --- | --- |
| 模型允许 | 继续下游检查，保留下游决定 |
| 模型明确拒绝、允许人工回退且策略为 `ask` | 下游允许后请求官方人工审批 |
| 模型拒绝、策略为 `never` 或关闭人工回退 | 拒绝，不创建人工请求 |
| 模型错误、超时、非法结果、路由不可用、固定上下文超限 | 拒绝，不转人工 |
| 调用取消、关闭或卸载 | 取消在途调用 |

不覆盖下游已有拒绝、取消或询问。人工放行不证明工具最终成功，也不绕过后续核心检查。人工超时通过请求 signal 取消，迟到放行不能执行工具。

## 目录授权记忆

中风险文件操作经人工放行，在目标符合条件时记住“目录 + 操作类别”。后续同目录及子目录、同类别的中风险拒绝可复用授权；仍执行模型审查及下游检查。

- 创建与编辑分别授权。
- 高危操作每次询问，放行仅本次生效。
- 删除、移动、相对路径和未知操作不保存授权。
- 敏感路径、凭据文件、过宽根目录、链接及重定向路径不复用授权。
- 仅保存在当前插件实例内存，最多 200 条，超出淘汰最早条目；重启或重新加载后清空。
- 设置页显示范围与使用次数，可撤销全部授权。

弹窗根据实际范围显示目录记忆或“仅本次生效”。授权保存成功或失败记录在历史中；保存失败时本次放行有效，后续仍需询问。

## 配置

通过官方 Settings / ConfigEditor 保存，以 revision 防止覆盖并发修改。失败保留草稿；过期时取消并重新读取后再编辑。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `false` | 注册或关闭 Auto |
| `reviewerProvider` | 空 | 与 model 同时完整或留空 |
| `reviewerModel` | 空 | 审查模型，由目录选择 |
| `reviewerEffort` | 空 | 模型支持的深度，空为适配器默认 |
| `fallbackToSessionRoute` | `true` | 无专用路由时使用会话 provider/model |
| `maxContextBytes` | `32768` | UTF-8 字节预算，整数 1–1048576 |
| `historyLimit` | `20` | 历史条数，整数 0–1000；0 不发送历史分区 |
| `includeProjectInstructions` | `true` | 是否单独加入项目指令分区 |
| `temperature` | `0` | 温度，0–2 |
| `timeoutMs` | `20000` | 模型超时，整数 1–300000 毫秒 |
| `logDecisions` | `true` | 日志记录工具、路由、风险、决定和耗时 |
| `manualFallback` | `true` | 明确拒绝是否可转人工 |
| `manualApprovalTimeoutMs` | `60000` | 人工超时，整数 1000–300000 毫秒 |

启用且关闭回退时需完整专用路由。会话回退不携带专用深度，无法获取会话路由时拒绝。热改影响后续审查，在途审查保持入口快照；关闭立即停止准入并取消在途审查。

上下文按策略、环境、项目指令、历史、待审动作排列。超限先裁最旧历史，再裁项目指令；策略、环境及待审动作不裁。固定分区仍超限则拒绝。关闭单独项目指令分区时，项目指令可能作为历史约束进入请求，受历史上限控制。

## 审批历史

```text
<profile>/dsh-auto-review-router/approval-history/<session-id的SHA-256>.jsonl
```

记录模型、下游、人工审批及框架报告结果。Router 发起的人工请求在超时判断和授权处理后统一记录最终结果，保留官方事件关联；核心人工审批仍由事件观察记录。

`reported-ok` 仅代表框架报告成功，不证明工具体或副作用成功。会话轮次末尾提供摘要，详细阶段及数据缺口在历史页查看。

每个会话账本上限 16 MiB，无自动轮转。写队列和等待有界，存储失败不改变审批决定，健康状态报告缺口。仅同一 Host 进程串行写入，无跨进程文件锁。

历史不保存原始参数、模型请求或工具内容。原因摘要采用尽力遮罩，不能保证识别所有秘密；审批弹窗展示的具体调用摘要与持久历史记录范围不同。

## 启停与冲突

与官方 `dsh-experimental-auto-review` 共用 Auto 名，冲突保留先注册者并显示错误；也应避免与 `dsh-codex-connect.enableAutoReview` 同时启用。

关闭或正常卸载先停止准入、取消审查，再将现有 Auto 会话收紧为只读，保留审批策略。成功后撤销 Auto；重新启用不会自动提升只读会话权限。

枚举或收紧失败时，热关闭保留拒绝守卫并显示错误，后续配置通知可重试。强制销毁 fiber 且日志无法写入时，宿主可能撤除守卫，插件不能保证已收紧；需检查失败状态并处理相关会话权限。

## 验证

从仓库根目录执行：

```sh
node tools/verify.mjs --pkg dsh-auto-review-router --quiet
node scripts/check-manifest.mjs
```

测试覆盖决策协议、上下文、配置、SDK 人工审批、授权、历史和启停。缺 workspace peer 时，可设置 `DSH_APP_ROOT` 指向官方安装目录，只读解析依赖，不修改安装树。

## 未核实项

- 跨核心版本、强制卸载故障及恶意同机并发路径交换的完整保证。
